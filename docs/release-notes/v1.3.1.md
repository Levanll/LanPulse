## 本次更新

修掉更新检测的两个问题。其中第一个会让这个功能在默认设置下**完全不工作**。

> 🌐 **官方网站**：https://levanll.github.io/LanPulse/ —— 中英双语，含截图与安装说明。

### 修复

**更新检查在默认配置下永远不会执行（中危）**

1.3.0 的更新检查由启动后 2.6 秒的定时器触发，而默认开启的体检在 0.4 秒就起来、
要跑十几秒网络探测。两者共用同一个后台任务队列，所以定时器触发时队列几乎
必然仍在忙。

1.3.0 的处理是「忙就跳过这一轮」，看起来安全，实际后果是：**每轮都跳过**。
你在同意弹窗里选了「开启」，设置里也确实是开着的，但更新提示再也不会出现。

现在改为：忙时不丢弃，记下待补标志，等体检结束后立刻补一次。成功与失败
两条路径都会兑现，不会因为一次失败的体检就让更新检查永久延后。

**正常的「无更新」结果被误记为警告（低危）**

查询接口的约定是「没有更新、或任何失败都返回 null」。上一版把 null 也当成
「非预期结果」记了一条 WARNING，导致每次正常启动都会往日志里写一条
`更新检查收到非预期结果，已忽略: NoneType`。绝大多数情况下这是误报，
排障时反而会掩盖真正的问题。现在 null 静默处理，只有真的收到错误类型才告警。

### 说明

这个版本只包含修复，没有新功能，界面与操作方式没有变化。

如果你还在用 1.3.0，更新提示不会自动出现——正是上面这个缺陷导致它不工作。
请手动下载 1.3.1 覆盖安装，之后的版本才会恢复正常提示。
