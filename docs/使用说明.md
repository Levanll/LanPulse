# LanPulse 使用说明

一款帮你**检查电脑网络哪里出了问题，并一键修好**的小工具。
所有检测和修复都在你自己的电脑上完成，**不联网、不上传任何数据**。
界面支持**中文 / English** 两种语言，可在设置里随时切换，无需重启。

---

## 一、安装

提供两种方式，任选其一：

| 方式 | 文件 | 适合 |
|---|---|---|
| **安装包**（推荐） | `LanPulse-1.0.0-Setup.exe` | 想要开始菜单快捷方式、能随系统卸载 |
| **绿色包** | `LanPulse-1.0.0-win64-portable.zip` | 不想安装、想放 U 盘里带走 |

### 安装包

双击运行，按向导完成。可以选择"仅为我安装"（装到用户目录，**不需要管理员权限**）或"为所有用户安装"。

> 首次运行如果弹出"Windows 已保护你的电脑"，点击 **更多信息 → 仍要运行**。
> 这是因为软件没有购买数字签名证书，不代表软件有问题。

### 绿色包

解压到任意目录，双击 `LanPulse.exe` 即可。卸载时直接删掉整个文件夹。

**备份和日志不在程序目录里**，而在 `%LOCALAPPDATA%\NetPulse\`，所以删程序不会丢备份。

---

## 二、关于管理员权限

**不点管理员权限也能正常体检**，只是有几项修复无法执行。

软件启动后如果是普通权限，左下角会显示"普通权限运行"。点击 **以管理员身份重启** 并在系统弹窗里点"是"，才能执行修改系统设置的修复（改 DNS、改 HOSTS、改防火墙等）。

## 三、设置

点侧栏底部的 **设置**。这里分六组：

### 通用

| 项目 | 说明 |
|---|---|
| **界面语言** | 跟随系统 / 中文 / English。切换后**立即生效**，已打开的页面会一起刷新 |
| **网络区域** | 自动识别 / 中国大陆 / 国际 / 亚太。见下一节 |
| **启动时自动体检** | 默认开启。关闭后打开软件不会自动跑检测 |

### 关于"网络区域"

这是本软件能**在不同国家、不同网络环境下正确工作**的关键。

检测需要"往哪里打"来验证网络通不通。但中国用 `223.5.5.5` 作基准、用百度测解析；到了欧洲，这些目标本身就不通或很慢，若还用它们判断，会把**完全正常的网络误报成故障**。

所以软件内置三套"区域剖面"，每套有自己的：

- 解析测试域名（CN：百度/腾讯/淘宝/B站；Global：Google/Cloudflare/Wikipedia/GitHub）
- 连通性探测目标（CN：阿里/腾讯 DNS；Global：Cloudflare/Google）
- MTU 实测目标
- 推荐的公共 DNS 方案
- **判定阈值**（跨境的正常延迟本来就比国内高，用同一把尺子会把正常链路判成"高延迟"）

**自动识别**综合三个信号：实测延迟打分 → 系统时区 → 系统语言。全部在本机完成，**不向任何第三方查询你的 IP 归属**。

自动识别不准时（例如用着海外 VPS 但在国内、或跨国专线），手动选一个区域即可。

### 检测

| 项目 | 说明 |
|---|---|
| **允许联网探测** | 关闭后所有网络请求跳过，只读本机配置。适合完全离线环境或极度注重隐私的场景 |
| **探测超时倍数** | 网络很慢的地区（卫星、跨境、老旧宽带）可调到 2.0–4.0，避免正常慢速被误判成故障 |

### 备份

| 项目 | 说明 |
|---|---|
| **备份保留数量** | 默认 30 个会话，超出后自动清理最旧的 |

### 安全

| 项目 | 说明 |
|---|---|
| **高风险动作额外确认** | 执行高危修复（协议栈重置、HOSTS 恢复默认）前要求再次确认 |

### 报告

| 项目 | 说明 |
|---|---|
| 默认报告格式 | HTML / JSON / TXT |
| 报告中包含原始证据 | 关闭后报告更简洁，但排障信息会减少 |

### 数据管理

- **打开数据目录** —— 备份、日志、设置都在这
- **打开设置文件** —— 直接编辑 `settings.json`
- **恢复默认设置** —— 不影响备份与日志

## 四、看结果：总览页

打开就是这一页，最直观。

**中间那个大圆环是你的网络健康分（0-100）：**

| 分数 | 颜色 | 含义 |
|---|---|---|
| 85-100 | 绿色 | 网络状态良好 |
| 60-84 | 橙色 | 存在问题，建议处理 |
| 0-59 | 红色 | 有严重问题，需要修复 |

圆环下方一句话说明整体情况，右侧"发现的问题"会列出具体哪几项不正常。

## 五、修问题：一键修复页

点左侧 **一键修复**。

### 你会看到什么

每个可修复项都列出来了，每一项都写着：

- **做什么**（例如"切换至公共 DNS 服务器"）
- **风险等级**（低 / 中 / 高）
- **具体改动**（例如 `223.5.5.5、223.6.6.6 → 223.5.5.5、119.29.29.29`）

**高危操作默认不勾选**，需要你自己打勾：

| 项目 | 为什么是高危 |
|---|---|
| 重置 TCP/IP 协议栈 | 会清空第三方网络过滤驱动注册，**需要重启** |
| 重置 Winsock 目录 | 部分安全软件需重装组件，**需要重启** |
| HOSTS 恢复为系统默认 | 你手动加过的所有 HOSTS 记录都会丢失 |

### 两种执行方式

**① 先演练（推荐第一次使用）**

点 **先演练**。它会完整走一遍备份流程，但**不修改任何设置**。演练完会告诉你备份会话 ID，说明备份链路是通的。

**② 执行修复**

点 **执行修复**，会弹窗列出将要执行的全部项目和备份位置，确认后才开始。

执行过程中每一项会依次显示 `备份 → 执行 → 校验` 三个阶段：

- `✓ 已生效` — 成功且读回验证通过
- `已跳过` — 该项无需修改
- `✗ 失败` — 该项没成功，其它项继续执行

## 六、出问题怎么办：备份与回滚

**这是本软件最重要的安全承诺兑现处。**

### 手动做个备份

右上角 **手动创建备份**：在你准备手动改点什么之前，先存一份当前网络配置快照。

### 还原

1. 在左侧列表点选一个备份（右侧会显示它具体备份了哪些内容）
2. 点底部 **恢复到 xx-xx xx:xx 的状态**
3. 确认弹窗里会再次列出要还原的项目

还原时会显示"成功 N 项"。如果有项目因权限不足跳过，也会明确写出来（不是"失败"，是"需要管理员权限"）。

> **备份是普通文件，你能自己看。**
> 点 **打开备份目录** 会打开 `%LOCALAPPDATA%\NetPulse\backups\`。
> 每个会话的 `manifest.json` 是纯文本，`.reg` 文件双击就能导入注册表，`files\hosts.bak` 可以直接复制回去。
> **即使本软件坏了，这些备份你依然能手工还原。**

## 七、专项功能

### DNS 优化中心

**适合场景**：能上 QQ 但网页打不开、网页经常加载一半、某些网站时好时坏。

页面显示当前用的 DNS 服务器，并自动标出归属（阿里云 / 腾讯 / 114DNS / Google / Cloudflare 等，共 24 个已知服务商）。

**可选的 DNS 方案会跟随你设置的区域变化**：在中国大陆你会看到"阿里+腾讯"、"114DNS"；切到国际区域则推荐"Cloudflare+Google"、"Quad9"。

选好点 **应用所选方案**，改之前会自动备份当前 DNS。

### HOSTS 管理

**适合场景**：怀疑网站被劫持、某些网站莫名打不开、装了广告过滤想确认效果。

| 判定 | 含义 | 建议 |
|---|---|---|
| 正常 | 普通映射 | 不用管 |
| 屏蔽 | 指向 `0.0.0.0` 等黑洞地址 | 通常是广告过滤软件或破解补丁写的。若网站是你需要的就清理 |
| 疑似劫持 | 百度、QQ、淘宝等大站被指向陌生 IP | **立即清理，并全盘杀毒** |

底部两个按钮：

- **清理异常记录** — 只删"屏蔽"和"疑似劫持"两类，其余行原样保留
- **恢复系统默认** — 整个文件替换成系统模板，**你加的所有记录都会丢**，非必要别用

> 想手动编辑：点右上角 **高级编辑**。

### 诊断详情

11 项检测的完整结果。左边表格是结论，点任意一行，右侧展开该项的：
- 具体指标（每条带 ✓/✗ 标识）
- 处理建议
- **原始证据**（JSON 格式的全部原始数据）

### 报告与日志

**导出报告**：HTML（单文件网页，含全部证据）/ JSON（结构化）/ TXT（纯文本）。
报告默认存到桌面。**报告里只有本机网络配置和检测结论，不含任何个人数据**。

**操作审计流水**：每次体检、修复、回滚、导出的记录都在这里。

## 八、环境自检

左下角或设置里可进入，检查 8 项运行条件：

```
操作系统      是否 Windows 10 及以上
管理员权限    是否已提权
PowerShell    是否可用（检测引擎依赖它）
netsh         是否可用
HOSTS 可读    能否读取 HOSTS 文件
HOSTS 可写    是否具备写权限
备份目录      备份目录是否可写
系统时间      时间是否明显错误（时间错会导致证书校验失败）
```

## 九、常见问题

**Q：体检时某项提示"跳过"是什么意思？**
表示该项在当前条件下无法检测。最常见是权限不足（非管理员读不到完整防火墙状态）。报告里会写明原因。

**Q：修复后需要重启吗？**
只有两个动作需要：重置 TCP/IP 协议栈、重置 Winsock 目录。执行后会明确提示。

**Q：修复失败了怎么办？**
去 **备份与回滚**，找到刚才那次会话，点还原。

**Q：我怕它改坏，能先看看要改什么吗？**
能。每项都写了 `before → after` 的具体改动；也可以点 **先演练**。

**Q：切换语言后，之前的体检结果会跟着变吗？**
**部分会。** 界面文字、按钮、设置项、结论摘要会立即跟随。但**已经生成的详细说明**（逐条证据描述）保持原来的语言——这些文案在检测时就已生成。想全部换语言，重新体检一次即可。

这是已知限制，原因是检测在后台线程执行，若当场翻译则无法二次翻译；详情文案含大量动态实测数值，用模板难以完整表达。

**Q：会不会收集我的信息？**
不会。代码里没有任何上传逻辑，报告只在本地生成。测试时你可以用抓包工具验证——它只会发出 DNS 查询和 ping 用的 ICMP 包，不带任何本机信息。

**Q：自动识别的区域不对怎么办？**
在设置里手动指定区域即可，检测立刻按该区域的探测集和阈值执行。

## 十、它不会做什么（明确的边界）

1. **不会自动修改 VPN 网卡。** TAP / Wintun / WireGuard 等虚拟网卡会被识别为虚拟设备，不参与 DNS 与 MTU 优化决策，以免破坏你既有的 VPN 配置。
2. **不会修复硬件故障。** 网卡接触不良、光猫故障、运营商断网这类问题，它只能告诉你"哪里不通"。
3. **执行"重新获取 IP 地址"时网络会中断 3-10 秒。** 这是 DHCP 续租的正常过程。
4. **需要管理员权限的修复在普通权限下会被拦截并提示**，不会静默失败。

## 十一、文件位置

| 内容 | 位置 |
|---|---|
| 程序（安装版） | `%ProgramFiles%\LanPulse` 或 `%LOCALAPPDATA%\Programs\LanPulse` |
| 程序（绿色版） | 你解压的位置 |
| 备份 | `%LOCALAPPDATA%\NetPulse\backups\` |
| 设置 | `%LOCALAPPDATA%\NetPulse\settings.json` |
| 日志 | `%LOCALAPPDATA%\NetPulse\logs\app.log` |
| 操作审计 | `%LOCALAPPDATA%\NetPulse\logs\audit.jsonl` |

> **卸载：** 安装版用"设置 → 应用"或开始菜单里的卸载项。卸载时会**询问是否保留备份**，默认保留——你的网络配置备份不应该因为卸载就没了。
> 绿色版直接删文件夹；连备份也想去掉，再删 `%LOCALAPPDATA%\NetPulse\`。
